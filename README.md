# GhosTTY

Initial Node.js CLI skeleton.

## Quickstart

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the CLI:

   ```bash
   make run
   # or npm run run
   ```

3. Lint the project:

   ```bash
   make lint
   # or npm run lint
   ```

4. Execute tests:

   ```bash
   make test
   # or npm test
   ```

## CLI usage

```bash
node src/main.js --help
node src/main.js --version
```
